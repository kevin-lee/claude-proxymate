# [0.7.0](https://github.com/kevin-lee/claude-proxymate/issues?q=is%3Aissue%20is%3Aclosed%20milestone%3Am10) - 2026-09-27

## New Features

* Replace the screenshot **Getting Started** carousel with a motion-graphic intro and a guided tour over the real controls (#67)

  The old carousel showed two screenshots of a toolbar layout that no longer exists, and it taught copying the command, which is only needed in *Manual* mode since *Global* became the default. Screenshots go stale whenever the UI changes, so the new onboarding uses no images.

  - **Motion intro**: The onboarding modal now plays a live animation that shows Claude Code sending a request through Claude Proxymate to `api.anthropic.com` and the capture appearing in the app. It has **Skip**, **Replay** and **Show me around** buttons. It uses the theme colors, so it works in both the light and dark themes, and it shows a static end frame when the system asks for reduced motion.
  - **Guided tour**: A 5-step spotlight walks through the real **Start Proxy** button, the **Route Claude** selector, the command box, the **Captured Requests** list and the detail tabs. A callout moves to another side when there is no room for it. While the onboarding runs, the rest of the app and the global shortcuts are disabled. Escape skips the tour and the arrow keys step through it.
  - **Start Proxy hint**: After the onboarding ends, the **Start Proxy** button pulses until it is clicked for the first time.
  - **Replay**: Getting Started can be replayed from the **About** panel.
  - **Localization**: The intro and the tour are available in English and Korean.
  - **Existing users**: The app now records the last onboarding version seen. Users who already saw the old carousel see the new onboarding once. It is recorded as soon as the onboarding opens.

## Internal Housekeeping

* Open a `claude-proxymate/<version>` Pull Request (PR) in [`kevin-lee/homebrew-tap`](https://github.com/kevin-lee/homebrew-tap) on release instead of pushing the cask update to its `main` (#69)

  - The release workflow's `tap` job now pushes the cask update to a new `claude-proxymate/<version>` branch and opens a PR to the tap's `main`, so each release is reviewed and merged by hand.
  - A new step fails the job if any `claude-proxymate/*` branch already exists in the tap. The tap deletes merged branches, so a leftover branch means a re-run for the same release or an earlier release PR that is still open or was closed without merging.
  - `HOMEBREW_TAP_TOKEN` now needs read and write access to contents and pull requests on the tap.

* Run `coreNative/test` in the release workflow's test job, so a release cannot be built without the Scala Native core tests passing (#70)

* Fix README errors (#70)

  - Remove references to build scripts that are not tracked, and document DMG packaging with `sbt prodUi` and `npm run dist:mac`.
  - Document the Request Filter and its server, Electron and renderer parts.
  - Update the test count, the test commands, the Scala.js output path note, the project structure and the release workflow details.
