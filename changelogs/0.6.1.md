# [0.6.1](https://github.com/kevin-lee/claude-proxymate/issues?q=is%3Aissue%20is%3Aclosed%20milestone%3Am9) - 2026-09-27

## Fixes

* Update model pricing for Claude Opus 5.5, and price fast mode, US-only inference and web search (#63)

  The cost breakdown used the 2026-09-10 rate table, which predates Claude Opus 5.5, so `claude-opus-5-5` was billed at the Opus 5 rates. Captured responses also carry three pricing inputs that the app ignored: fast mode, US-only inference and web search.

  - **Claude Opus 5.5**: Opus 5.5 now has its own tier at $4 input / $20 output per million tokens, with cache reads at $0.20 instead of $0.50. An unrecognized Opus model name such as `claude-opus-6` now falls back to the Opus 5.5 rates as the current Opus.
  - **Fast mode**: A capture whose response reports `usage.speed: "fast"` is priced at 2x all token rates, including cache writes and cache reads.
  - **US-only inference**: A capture whose response reports `usage.inference_geo: "us"` is priced at 1.1x all token rates. It stacks with fast mode.
  - **Web search**: Web searches are priced at $10 per 1,000 searches, separate from the token rates. The token popover shows them as their own `N × $0.01` row, and the **Analysis** cost card adds them to the total as a separate row, outside the token segment bar.
  - **Modifier notes**: When a capture was billed with fast mode or US-only inference, the token popover, its copied text and the **Analysis** cost card show a note saying so.
  - **Pricing reference**: The pricing date is now 2026-09-27. Claude Haiku 3 is no longer on the pricing page but stays as a retired tier, so older captures still price correctly.

  Captures without any of these modifiers are priced exactly as before.

## Internal Housekeeping

* Update the Homebrew cask in [`kevin-lee/homebrew-tap`](https://github.com/kevin-lee/homebrew-tap) automatically on release, and publish DMG checksums (#61)

  - Each release now publishes a `Claude-Proxy-<version>-<arch>.dmg.sha256` file next to each DMG. The release job verifies the DMGs against them before publishing.
  - A new `tap` job runs after the GitHub Release. It checks the published DMGs against the published checksums, updates `Casks/claude-proxymate.rb` in the tap with the new `scripts/update-cask.sh`, and keeps the previous cask as `claude-proxymate@<previous>.rb`. `brew upgrade --cask claude-proxymate` picks up a release without a manual cask update.
  - Every workflow declares its own permissions, so it works with a read-only default `GITHUB_TOKEN`. Only the release job gets `contents: write`.
  - Every action is pinned to the commit SHA of its latest release.

* Count the release artifacts with bash glob arrays instead of parsing `ls` output in the release workflow's sanity check, so `actionlint` passes on every workflow (#62)

* Add `scripts/repro/concurrent-wedge.py`, a concurrent-load script that reproduces the Scala Native trap-yieldpoint wedge fixed in 0.6.0 (#57).
