# [0.8.1](https://github.com/kevin-lee/claude-proxymate/issues?q=is%3Aissue%20is%3Aclosed%20milestone%3Am12) - 2026-11-10

## Fixes

* Price Claude Fable 5.2 with its own rates, and refresh the price list date (#92)

  The rate table is checked against the [Claude pricing page](https://platform.claude.com/docs/en/about-claude/pricing) on 2026-11-10. Every other rate, the fast mode and US-only inference multipliers, and the web search price still match the page.

  - **Claude Fable 5.2**: `claude-fable-5-2` and `claude-mythos-5-2` had no tier, so they were priced as Fable 5 at $10 input / $50 output per million tokens, with cache reads at $1. Input and output were 1.25x too high, and cache reads were 5x too high. They now have their own tier:

    | Model                         | Input | 5m cache write | 1h cache write | Cache read | Output |
    |:------------------------------|------:|---------------:|---------------:|-----------:|-------:|
    | Claude Fable 5.2 / Mythos 5.2 |    $8 |            $10 |            $16 |      $0.20 |    $40 |

    Fast mode applies 2x on top of these rates ($16 / $80). An unrecognized Fable or Mythos model name such as `claude-fable-6` now falls back to the Fable 5.2 rates as the current Fable.
  - **Pricing reference**: The pricing date is now 2026-11-10.

## Internal Housekeeping

* Retry the Apple ticket lookups in the release build (#90)

  The v0.8.0 release build failed twice on the `macos-15-intel` runner because the connection to Apple's CloudKit server dropped (error 68, `NSURLErrorDomain -1005`). The release workflow now runs `electron-builder` again, up to 3 times, only when stapling fails. It also retries `xcrun stapler validate` up to 5 times, with a longer wait each time. All other errors still fail at once.
