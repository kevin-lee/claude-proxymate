# [0.6.0](https://github.com/kevin-lee/claude-proxymate/issues?q=is%3Aissue%20is%3Aclosed%20milestone%3Am8) - 2026-09-21

## New Features

* **Selection to rule** now works on assistant response text in the **Messages** tab (#55)

  Selecting text inside an `ASSISTANT` card did nothing, because the selection menu only accepted a selection whose ends were both inside the user's own typed block. A phrase in a response becomes part of the request body on the next turn, so there was no inline way to filter it even though the filter engine already applied *Claude* and *Both* scoped rules to assistant messages.

  - The selection menu now opens on assistant text as well as typed text, still requiring both ends of the selection to be in the same block.
  - The menu is positioned against the message body instead of the text block, because the assistant text block scrolls on its own and would otherwise clip the menu.
  - A rule added from a selection keeps scope *Both* for both roles, so there is no new configuration and no change to `request-filter.json`.

## Fixes

* Fix the proxy binary wedging under concurrent requests (#57)

  Claude Code reported the API as unreachable after a few dozen requests through the proxy. The shipped `claude-proxymate-server` is a Scala Native release build using the multithreaded Commix Garbage Collector (GC), and in release mode Scala Native uses trap-based GC yieldpoints. On macOS the fault at the yieldpoint is lost for some threads, so when a collection starts while two or more requests are in flight, those threads spin at the poll forever, the collector waits for them, and the process wedges until it aborts on the sync timeout. Eight concurrent requests reproduce it within the first two rounds, while sequential traffic never does.

  - The proxy binary is now linked with trap-based GC yieldpoints turned off. The release and build workflows set the variable for every job, and the build fails early with an explanation when it is missing, so a binary cannot be linked without it by accident.
  - The upstream `curl` call is annotated as blocking, so a collection no longer waits for an in-flight request to the Anthropic API.
  - The desktop app now drains and logs the proxy's standard error output as `proxy stderr:`. Nothing was reading that pipe before, so the GC warnings that pointed at this problem were invisible.
  - `README.md` documents the export needed for a native link, including the note that a running sbt must be restarted after exporting it and that the first link after the change needs `proxyServer/clean`.

  A binary linked this way survived 640 concurrent requests with no safepoint warning.

* Stop the message card from clipping the selection-to-rule and badge menus in the **Messages** tab (#53)

  When the text block was the last item in a card, the card clipped the menu at its bottom border and only the top edge was visible. The inline badge menu was clipped in the same case.

  - The message card no longer clips its contents, and the card header keeps its rounded top corners on its own.
  - A menu that extends below the last card is scrolled into view when it opens. The list does not move when the menu is already fully visible.
