# [0.4.1](https://github.com/kevin-lee/claude-proxymate/issues?q=is%3Aissue%20is%3Aclosed%20milestone%3Am6) - 2026-09-10

## Fixes

* Hide the address-bar **Filter** badge while **Filtering** is switched off (#39)

  Configured rules no longer make the button show a rule-count badge when filtering is paused. The button's tooltip explains that filtering is off and shows how many configured rules are not being applied. Switching filtering back on restores the active button and badge.

* Update model pricing, cache-write costs and token estimates (#41)

  - **Model pricing**: The app's pricing table is dated 2026-09-10. Claude Opus 5 now uses the Opus rates of $5 input / $25 output per million tokens instead of falling back to Sonnet rates. Sonnet 5 stays at $2 input / $10 output per million tokens, with the previous date-based price increase removed. Claude Fable 5.1 and Claude Mythos 5.1 get a separate tier with cache reads priced at $0.25 per million tokens instead of $1.00.
  - **Model matching**: Unrecognized model names containing a known Claude family name now use that family's latest configured pricing tier. Names with no recognized family fall back to the premium Opus rates.
  - **Cache writes**: The token cost popover and request analysis now calculate 5-minute and 1-hour cache writes at their respective rates. When a capture includes 1-hour writes, the breakdown shows separate rows or segments for each duration. Captures without a duration breakdown continue to treat all cache writes as 5-minute writes.
  - **Token estimates**: Request token estimates now use 2.7 bytes per token instead of 3.5, producing roughly 30% higher estimates for the same content. Request Filter size-threshold estimates use the same conversion.
  - **Pricing reference**: The token popover displays the updated pricing date and links **Official Docs** to `platform.claude.com`.
